# Hormozi Proposal Review Output Template

Use this structure unless the user explicitly asks for a shorter or different format.

## 1. Executive verdict

- One-line verdict: would you try to sell this as-is?
- One or two sentences on the core reason.

Suggested language:
- "I would not try to scale this as-is because the offer is too vague and under-proven."
- "This is directionally solid, but the proof and CTA are too weak for premium pricing."

## 2. Proposal dossier

Summarize what the material appears to be selling.

Fields:
- Buyer / ICP:
- Pain:
- Desired outcome:
- Mechanism:
- Price / terms:
- Proof present:
- Bonuses / support:
- Guarantee / risk reversal:
- CTA / next step:
- What is unclear:

## 4. Biggest leaks

List the top 3–5 conversion leaks.

For each leak use this subformat:
- Problem:
- Evidence from proposal:
- Why it hurts:
- Principle violated:
- Fix:

## 5. What is strong

Capture what should be preserved.
Do not skip this section just because the work is weak overall.

## 6. Section-by-section critique

Walk through the important parts of the proposal.
Useful subsections include:
- Headline / opening
- Offer description
- Proof
- Pricing
- Bonuses / support
- Guarantee
- CTA
- Lead magnet / traffic logic

## 7. Rewrites

Prioritize concrete rewrites.

Suggested items:
- Offer one-liner rewrite
- Headline rewrite
- Offer name rewrite
- CTA rewrite
- Guarantee rewrite
- Bonus rename / restructure

When possible, provide before/after style suggestions.

## 8. Considerations

This is where nuance belongs.

Include:
- assumptions you had to make
- missing information
- where the recommendation changes by industry or sales cycle
- ethical concerns
- whether the proposal is trying to scale before earning it

## 9. Highest-leverage next actions

End with a short action plan.

Suggested structure:
1. Fix this first:
2. Then test this:
3. Do not change this yet:

Optional closing line:
- "If you want, I can now rewrite the proposal into a stronger Hormozi-style version without the fluff."
